# SustainIQ frontend

React + Vite + Tailwind CSS single-page app for SustainIQ.
See the [main README](../README.md) for the project overview and setup.

```bash
npm install
npm run dev     # development server on http://localhost:5173
npm run build   # production build in dist/
npm run lint    # oxlint
```

Set `VITE_API_URL` (see `.env.example`) to point to the backend; default is `http://localhost:8000`.
