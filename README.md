# SustainIQ

AI-powered sustainability assessment tool for German SMEs. Companies enter
operational data (energy, emissions, waste, water) and receive EU sector
benchmarking, a CSRD/ESRS gap analysis, AI recommendations, and a PDF report.

**Status:** work in progress (Phase 1 — MVP).

Tech stack: React + Vite + Tailwind CSS (frontend), Python + FastAPI (backend),
Anthropic Claude API (analysis text), SQLite (saved assessments).
